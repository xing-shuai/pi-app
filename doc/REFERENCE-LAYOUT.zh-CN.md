# 用户截图布局基准（第二轮）

本轮不再以“Claude 配色”代替布局复刻。基准是用户提供的 Chat 和 Code 两张深色 Desktop 截图；私密对话标题、头像、订阅标记和模型名不复制进产品或测试种子。

## 几何与颜色

截图画布 1683×1593，应用矩形约为 `(25,16)–(1660,1546)`。按 1.25 device scale 归一化，对照窗口为 **1308×1224 CSS px**。

实际屏幕检测为 **DPR 1.5**；首次安装参考样式时采用 **83.3% UI 密度（5/6）**，使有效缩放为 1.25，与截图物理比例一致。外观设置中保留该密度档位，也可自行改回 100%。开发窗口对应尺寸为 1090×1020 DIP（物理约 1635×1530），不把测试用的 1308×1224 设计坐标误当成当前屏幕 DIP。

- 左侧栏约 **290 设计 px**，贯穿标题栏到账号区。
- 标题栏 **42 px**；菜单、侧栏开关、后退/前进、Chat/Code 图标切换都在左上角。
- 删除上一版的全宽居中模式条、执行环境横条、产品安全页脚和重复页面标题。
- 主背景取样 **#151515**，侧栏 **#111111**，竖向分隔 **#292929**。
- 输入框背景 **#20201f**，边框约 **#373736**，选中导航 **#343434**。
- Chat 输入区最大宽 **768 px**，空会话时与问候行一起居中；输入框初始约 **122 px**，模型/上下文控制放在框外下方。
- Code 顶部是问候行，输入区固定在底部；Local/SSH 与目录芯片在输入框上方，模型/思考等在下方。环境选择菜单上弹，不再使用顶端原生 select。
- 环境菜单约 **240 px**，包含 Local、Cloud、Remote Control、SSH；未实现的执行方式明确禁用，不静默回退本机。
- 账号区采用本地真实用户名与 Local 标识，不冒充 Claude 账户或 Pro 订阅。

## 真实功能与视觉状态

- Chat 的 New、Recents、搜索/排序、会话打开/管理继续使用实际后端数据；新增窗口后退/前进支持实际导航。
- Code 继续使用现有会话/项目实现，不为了截图填充用户的真实项目名或聊天历史。
- Scheduled/Routines、Customize 跳转到已有任务和资源设置页面。
- Projects 知识库、Artifacts、Design、临时 Chat、Chat 语音对话尚未实现的部分保留明确禁用状态和提示，不给出假的可用能力。
- 模型、推理级别和权限状态显示真实值；不会为了与示例文字相同，把实际 reasoning off 标成 High 或把零工具 Chat 标成 Auto。

## 补充细节基准

- Local / SSH 只决定执行位置，远端不换独立页面；已有会话/文件/Git/终端布局不变。
- 连接对话框宽 624 设计 px；远端目录框含路径 + Go、面包屑与目录列表；信任框宽 480px，默认焦点在 Cancel，实际主机和目录可核对。
- Settings 使用 inset 56px / 40px 的浮层，左导航 254px、内容 padding 28px，保留并禁用背景交互。账号菜单从左下向上弹出，宽 310px；上下文/用量环在 Composer 工具条右侧。
- 不复制截图私人邮箱、组织/订阅身份、配额百分比或重置时间。服务端不支持的条目禁用/说明，不用视觉复刻伪装功能。

## 新增菜单与 Scheduled 细节

- Code 模型一级菜单仅显示真实当前/最近/可用常用项，More models 展开侧菜单；侧菜单支持搜索、provider 分组和分页，按窗口边界翻转/钳制，不硬编码截图中的 Claude 型号、Default 或计费权限。
- Effort 弹层约 264px，实际级别与 Faster/Smarter 滑块呈现；不伪造 Recommended。仍使用 SDK 实际能力、异步确认和模型级绑定，未知能力不宣称全部支持。
- Scheduled 为 Yours/Templates、功能性搜索/筛选/排序、两列卡片；详情用双栏属性/指令/历史，实际输出配 Runs 侧栏。当前只是 Local 账本与只读输出，不以参考图的 Composer、PR 或完整工具记录伪装后端未实现能力。
- 主菜单统一 `16px / 1.5 var(--font-sans)`、36px 行高，保留键盘导航/焦点恢复。提示改用明确的 `data-app-tooltip`，自适应内容宽度、最大 320px、14px Sans、暗色无箭头；正确处理 zoom、Esc/点击/滚动/目标移除/overlay。不劫持所有原生 title，常用图标已主动迁移；Native BrowserView 交叠区域保守抑制，不用假对话框改变原生视图。

## 验证方法

Electron 测试先使用归一化 viewport 与 1.25 device scale，检查关键元素的实际 bounding box 和色值，输出空 Chat 与 Code 环境菜单截图；再以 1090×1020 / DPR 1.5 / 83.3% UI 密度验证真实屏幕对应尺寸与字体。截图比较排除应用外部的桌面背景，以及数据依赖的历史、模型名和头像。

布局以用户截图为准，不再自行追加营销副标题、提示卡片、额外品牌行。字体字形/栅格化受平台与可用字体影响，需要单独校准；以实际截图对照结果验收，不再用“换色完成”代替验证。

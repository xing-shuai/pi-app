# 订阅额度与 API 余额

Code 输入栏右侧的上下文/用量按钮保留本会话 token 与报告成本，并增加独立的 **Provider allowance / balance** 查询。打开弹窗或手动 Refresh 时才查询，不在启动时轮询，不把 token 成本当成订阅余额。

## 当前接入

- **OpenAI Codex OAuth**：官方返回的订阅窗口、已用/剩余比例、重置时间、计划名称、credits/unlimited/exhaustion（只在服务端确实返回时显示）。订阅额度不一定是货币余额，不换算成美元。
- **DeepSeek API**：官方返回的 CNY / USD 余额，保留各币种及 total/granted/topped-up 的原始十进制字符串。
- 其他 provider 暂不声称已实现；未登录、不支持、代理地址、请求失败和过期会显示具体状态，不填假的 0、Pro、剩余百分比或重置时间。

参考本机安装的 MIT `@narumitw/pi-usage` 0.61.1，适配了最小归一化逻辑并保留许可证。不会调用或注册整个扩展，也不提供 /fast、额度重置兑换、购买或其他计费修改操作。

## 紧凑显示

弹窗默认只显示上下文估算、实际 provider/plan、额度窗口和总余额；额外窗口、充值/赠送明细、已报告 token/成本及技术说明在 **Show details** 中展开。宽度 360px、最高 420px，并根据视口和 UI 缩放收窄；滚动条为透明轨道的 4px 细条。

窗口时长来自真实 `windowSeconds`，不硬套 5 小时/周限额。金额/credits 以十进制字符串和整数运算格式化；只有省略了非零小数位才加 `≈`，完整原值保留在无障碍标签和主题提示中，不经浮点转换。相对重置时间仍保留绝对时间。

## 账户与权限边界

已有精确绑定的本地会话 worker 时，查询使用该 worker 的实际 ModelRuntime 和模型。只读重载的历史尚未绑定 worker 时，从已授权会话的当前分支/leaf 解析实际记录的 provider/model，并使用该 provider 的只读凭据解析账户；不新建会话、启动 worker/模型回合或 CLI，不加载扩展/MCP，也不回退默认模型、环境凭据或另一账户。已有 worker 请求失败不会换用另一来源重试。切换模型、会话、配置或账户后会重新核对身份，期间新建 worker 会使旧的只读查询失效。

无法验证的旧/损坏分支、超过 32MiB 的历史、仅由扩展注册而不在精确模型目录中的型号、缺失或将过期的 OAuth、命令式凭据/配置等仍明确不可查询；只读路径不执行凭据命令、不刷新/写回 auth。SSH/WSL 不走本机只读账户解析。

凭据留在主进程/worker 后端，只向两个固定官方 HTTPS 用量端点发送必要鉴权；界面只收到额度 DTO。自定义/代理 origin、重定向或不匹配账户拒绝，错误不回显 bearer、SDK 错误文本或配置对象。查询总预算 8 秒、响应最大 64 KiB、缓存 45 秒/最多 32 项，按带进程随机盐的账户/凭据/运行时指纹隔离。

当前 SSH/WSL 账户的额度还没有透传。远端界面会明确说明不支持，而不是借用本机登录或把本机凭据发送到服务器。真实余额需用户主动打开弹窗确认；自动测试使用临时合成 OAuth 和模拟 fetch，没有读取用户凭据或访问真实计费账户。

# Routine 的只读天气查询

普通 Chat 与旧的 Chat routine 默认不具备联网工具。把“杭州天气”写进指令不会自动授权联网；模型解释无法查询也可能正常完成执行。界面的 **Completed** 表示执行结束，不是独立验证了任务目标。

## 给现有任务授权

1. 在 Scheduled tasks 打开任务，选择 Edit。
2. 在 Chat 类型下勾选 **在线天气查询（只读） / Online weather lookup (read-only)**，阅读城市名称披露说明并保存。
3. 确认详情显示 **Chat+Weather**，再 Run now。关闭该选项并保存即可撤销；切换任务类型也会清除授权。

也可从 Templates 选择“杭州天气”；它只打开可编辑且可见授权的草稿，不会自动保存或运行。普通 Chat 对话没有因此获得天气工具。

## 实际边界

- 仅提供名为 `weather` 的只读工具，把城市名称及可选国家代码发送到 Open-Meteo 的固定公共 geocoding/forecast HTTPS 端点，不需要 API key。
- 不授权 shell、文件、通用 URL 请求、网页搜索、扩展、MCP 或知识库。Code routine 的原有权限不变。
- 只返回当前条件：匹配地点、温度/体感、风速、降水、WMO 天气代码、数据源观测时间与时区；不是多日预报，也不保证数据绝对实时。
- 模型不能指定 URL 或坐标。拒绝重定向；每次 HTTP 请求含流式读取总计限 8 秒、128 KiB，每次运行最多 6 次查询，不自动重试。
- 取消、超时和 SDK 释放都会中止天气请求，仍等待实际清理结算后才释放任务锁。网络、地点匹配或服务失败会作为安全工具错误交给模型，不伪造天气。

需要支持工具调用的模型及可访问 Open-Meteo 的网络。调度仍仅在应用开启且电脑唤醒时工作，没有离线 daemon、SSH routine 或 Cloud Runner。
